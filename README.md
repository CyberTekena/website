# Octopus Trading Card

An HTML/CSS exercise presenting an illustrated animal fact card. This repository is the `website` version.

## What it demonstrates

Semantic content, image presentation, the CSS box model, flexbox centering, borders, and shadows.

## Run locally

From the repository root, use Python 3 to serve the files:

```sh
python -m http.server 8000
```

Open http://localhost:8000/index.html. Serving the repository root also supports root-relative image paths.

## Structure

- [index.html](index.html) — card content and inline styles.
- The image asset is stored alongside the page.

## Related work

[Trading-Card](https://github.com/CyberTekena/Trading-Card) and [website](https://github.com/CyberTekena/website) contain closely related versions. They are presented as one learning project, not separate products.
